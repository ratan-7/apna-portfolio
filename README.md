# 🚀 Apna Portfolio

**A full-stack MERN portfolio with a fully dynamic, admin-editable public site.**

No hardcoding — every section (bio, skills, projects, experience, education, social links, resume) is managed from a secure admin dashboard and rendered live on the public site.

## ✨ Features

### 🌐 Public Site
- Dark / Light theme toggle, persisted across visits
- Sticky navbar with a live "active section" indicator
- Hero, About (README-style bio), Experience timeline, Education, live "Systems" stats panel, categorized Skills with progress rings, Projects with **real-time GitHub commit info**, Contact form, Footer
- Automatic GitHub commit fetching per project via the public GitHub REST API
- Visitor count & resume-download analytics tracking
- Fully responsive — mobile to desktop

### 🔐 Admin Panel
- JWT-based authentication with a **hidden, custom login path** (not the guessable `/admin/login`)
- Dashboard with live stats overview
- Profile & Bio management (name, role, tagline, README content)
- Social Links management (GitHub, LinkedIn, LeetCode, YouTube, Instagram, email, phone)
- Full CRUD for Skills, Projects, Experience, and Education
- Contact inbox with one-click "Reply via email"
- Real file uploads (project screenshots + resume PDF) via Cloudinary
- Mobile-responsive collapsible sidebar
